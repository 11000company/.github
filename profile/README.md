## Catálogo interativo

Quer analisar o trabalho com mais profundidade? Estamos estruturando um catálogo para que o visitante possa **abrir os sites, navegar pelas páginas e conhecer demonstrações seguras dos sistemas**.

**[Acessar o repositório do catálogo →](https://github.com/11000company/catalogo)**

O repositório contém um protótipo de interface. **Ainda não é uma demonstração pública hospedada.** As experiências completas serão vinculadas quando estiverem disponíveis.

O GitHub README funciona como uma vitrine de projetos e links. A navegação expandida dentro de uma página exige um catálogo web próprio; ambientes administrativos demonstrativos devem usar dados fictícios e permissões restritas.
